# Contributing to Cloud 9 UAP Project
We welcome contributions from **scientists, engineers, hackers, and UAP enthusiasts**!

## 🛠️ Ways to Contribute
1. **Data**: Add new UAP reports to `database/raw/`.
2. **Code**: Improve simulations, AI models, or dashboard.
3. **Hardware**: Design or build UAP-inspired drones.
4. **Research**: Publish papers or analyses in `papers/`.
5. **Outreach**: Help with collaborations (e.g., email Loeb/AARO).

## 📥 Pull Request Guidelines
1. Fork the repo and create a new branch.
2. Follow the folder structure.
3. Add tests for new code (if applicable).
4. Update READMEs to document changes.
5. Reference issues (e.g., "Fixes #123").

## 📜 Code of Conduct
- Be **respectful and collaborative**.
- **No classified data** (stick to public sources only).
- **Credit contributors** in commit messages.

## 🤝 Collaboration
- Email dean@cloud9assembly.org for partnerships.
